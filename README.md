# Budget Tracker

## Project Description
The Budget Tracker is a simple webpage that displays sample expenses
in a table, includes a budgeting video embed placeholder, and provides
collapsible usage instructions.

## Technologies Used
- HTML5
- CSS3

## Project Files
- `index.html`: Contains the expense table, budgeting video section,
  and collapsible help section.
- `style.css`: Contains header layout rules and spacing and responsive
  sizing for the video embed.
- `README.md`: Describes the project and its current limitations.

## Features
- Expense table with five hardcoded sample records.
- Budgeting Tips video section.
- Collapsible usage instructions.
- Responsive video sizing for narrow screens.

## How to Run
1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Review the sample expenses and expand the help section.

## Limitations
The expense records are hardcoded sample data. There is currently no
expense-entry form or functionality to add or save records. The video
embed uses a placeholder (`VIDEO_ID`) and must be replaced with a
YouTube video ID that allows embedding.
